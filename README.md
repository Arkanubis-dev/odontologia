# Centro de Psicología - Plataforma de Gestión Clínica & Consultas

Sistema integral de gestión para profesionales de la salud mental, psicólogos y terapeutas. Permite el manejo confidencial de historias clínicas, agenda de sesiones, notas de evolución y seguimiento de consultantes.

## Tecnologías

- **Framework:** Next.js 16 (App Router)
- **Lenguaje:** TypeScript
- **Estilos:** Tailwind CSS
- **Iconos:** Lucide React
- **Base de Datos & Autenticación:** Supabase

## Inicio Rápido

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Arkanubis-dev/odontologia.git
   cd odontologia
   ```

2. Instala las dependencias:
   ```bash
   npm install
   ```

3. Configura tus variables de entorno en `.env.local`:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=tu_supabase_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=tu_supabase_anon_key
   ```

4. Inicia el servidor de desarrollo:
   - Con doble clic en `iniciar.bat` (Windows)
   - O mediante terminal: `npm run dev`

5. Abre [http://localhost:3000](http://localhost:3000) en tu navegador.
